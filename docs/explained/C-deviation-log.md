# The deviation log

> **In plain words.** Every time a rule, a parameter or a gate changed during the build, one row was added here, with the date,
> the change, the reason, and whether the meaning of a gate changed. The list is complete: there were 22 entries, and none was
> removed. Wording here is a plain rephrasing of the project's own log. Numbers marked † come from that log and were not independently audited.

The last column answers one question: did the change make a gate easier or different in meaning? "No" means that every bar stayed as it was written.
"Yes" means the bar was untouched but the instrument or the rule of the run changed, and the row says how.
